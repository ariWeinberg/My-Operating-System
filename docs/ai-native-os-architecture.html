Guardrails

  • Never execute model-generated code in Ring 0 or a privileged native service.
  • Every accepted change preserves a CI-built, boot-tested VM artifact.
  • Every phase ends with a bootable, regression-tested release tag.
  • Security starts with paging and privilege separation; it is not a final hardening phase.
  • Distributed compute does not imply efficient cross-node tensor parallelism.
  • Production claims apply only to the published hardware and failure matrix.
